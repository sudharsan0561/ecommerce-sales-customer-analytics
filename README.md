# E-commerce Sales and Customer Analytics

## 📌 Project Overview

This project focuses on analyzing e-commerce sales and customer data using MySQL.

The objective of this project is to understand customer behavior, product performance, sales trends, revenue generation, and other important business metrics using SQL.

---

## 🛠️ Tools & Technologies

- MySQL
- SQL
- GitHub

---

## 🗄️ Database

Database Name:

`ecommerce_analytics`

### Tables Used

1. `customers`
2. `products`
3. `orders`
4. `order_items`
5. `payments`

---

## 🔍 Data Validation

Before performing the analysis, the data was checked for:

- Duplicate records
- NULL values
- Missing IDs
- Invalid relationships
- Negative prices and amounts
- Data consistency
- Record counts

---

## 📊 SQL Analysis

The project contains 45 SQL analysis questions divided into different difficulty levels.

### Basic Analysis

The basic analysis includes:

- Product price analysis
- Product category analysis
- Stock analysis
- Product status analysis
- Customer analysis
- Sales analysis

### Intermediate Analysis

The intermediate analysis includes:

- JOIN operations
- Customer order analysis
- Revenue analysis
- Product performance
- Subqueries
- GROUP BY and HAVING
- Business-oriented analysis

### Advanced Analysis

The advanced analysis includes:

- Common Table Expressions (CTEs)
- Window Functions
- ROW_NUMBER()
- RANK()
- Product revenue ranking
- Advanced sales analysis
- Customer and product performance analysis
